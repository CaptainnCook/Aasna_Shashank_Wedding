Digital wedding invitation · Mangsir 17, 2083 (Thursday, 3 December 2026) · Karki Banquet, Babarmahal, Kathmandu.

## Publish on GitHub Pages
1. On GitHub, create a new **public** repository (e.g. `aasna-shashank-wedding`).
2. Click **Add file → Upload files** and drag in everything from this folder: `index.html`, `music.mp3`, the six `.jpg` images and the whole `fonts` folder. Commit.
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and Save.
4. After a minute or two it is live at `https://<your-username>.github.io/<repo-name>/`.

## Background music
`music.mp3` (the song from the original invitation) is on by default. Where the browser allows it, it starts as soon as the page opens; phones usually block sound until the first touch, so there it starts on the guest's first tap or swipe. Tapping the ♪ icon stops it (the icon shows a line through it), and tapping again plays it. To change the song, replace `music.mp3` with another file of the same name.
